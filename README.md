# Smart Password Generator

## Overview

This project is a Java-based application that generates secure passwords using user details such as Name, PAN number, and Date of Birth. It also checks the strength of the generated password.

## Features

* Accepts user details
* Generates secure password
* Displays generated password
* Classifies password strength as Weak, Medium, or Strong
* Supports multiple users

## Technologies Used

* Java
* String Handling
* Methods
* Conditional Statements
* Loops

## File Included

* `PasswordGenerator.java`

## Sample Output

```text
Generated Password: BI@2006#34F
Password Strength: Strong
```

## How to Run

1. Compile the program:

```bash
javac PasswordGenerator.java
```

2. Run the program:

```bash
java PasswordGenerator
```
